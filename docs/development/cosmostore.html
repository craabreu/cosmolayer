Cosmostore#

The cosmostore command builds a segment-data store from .cosmo files (if one is not already present) and prints summary statistics for atom- and molecule-level charges, areas, and sigma profiles.

Build the segment data store (if missing) and print summary statistics for atom- and molecule-level charges, areas, and sigma profiles.

usage: cosmostore [-h] --storage-dir STORAGE_DIR
                  [--cosmo-files-dir COSMO_FILES_DIR]
                  [--smiles-to-filename SMILES_TO_FILENAME]
                  [--num-threads NUM_THREADS] [--sigma-scheme SIGMA_SCHEME]

Named Arguments#

--storage-dir

The directory to store (or load) the segment data.

--cosmo-files-dir

Directory containing the .cosmo files referenced by –smiles-to-filename. Required only if –storage-dir doesn’t already hold a built store.

--smiles-to-filename

Path to a JSON file mapping each SMILES string to its .cosmo filename (relative to –cosmo-files-dir). Required only if –storage-dir doesn’t already hold a built store.

--num-threads

Number of threads to use for every threaded step (segment averaging, sigma-profile binning). Defaults to every available CPU core – lower this on a shared machine to leave headroom for other users.

--sigma-scheme

Averaging scheme for every statistic (e.g. ‘cosmo-rs’, ‘cosmo-sac-2002’, ‘cosmo-sac-2010’). The store must already contain that scheme. Default: raw sigma.
