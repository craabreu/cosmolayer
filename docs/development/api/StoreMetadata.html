class cosmolayer.store.StoreMetadata(num_molecules, num_cosmo_parse_failures, schemes=<factory>)[source]#

Typed view of a SegmentStore’s metadata.json.

Parameters:

  • num_molecules (int) – Number of molecules successfully stored.

  • num_cosmo_parse_failures (int) – Number of molecules skipped because they failed to parse or validate (only possible with ignore_errors=True, see SegmentStore.from_cosmo_files).

  • schemes (dict[str, AveragingScheme]) – Averaging schemes this store has computed sigmas for, keyed by scheme name.
