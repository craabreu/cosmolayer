SigmaGrid#

class cosmolayer.store.SigmaGrid(max_abs_sigma=0.025, num_points=51)[source]#

A symmetric, evenly spaced grid of sigma-profile points.

Parameters:

  • max_abs_sigma (float, optional) – Bounded sigma-profile value at each end of the grid, in e/Å², by default DEFAULT_MAX_ABS_SIGMA.

  • num_points (int, optional) – Number of grid points, by default DEFAULT_NUM_POINTS. An odd count puts a point at sigma = 0; an even count straddles it.

Examples

>>> grid = SigmaGrid(max_abs_sigma=0.025, num_points=51)
>>> round(grid.bin_width, 6)
0.001
>>> len(grid)
51
>>> grid.values[0], grid.values[-1]
(np.float64(-0.025), np.float64(0.025))
